# Таблица

Интерактивное табличное приложение — чистый frontend на HTML/CSS/JavaScript без серверной части.

## Возможности

- Редактирование ячеек в реальном времени
- Поддержка формул (`=A1+B2`, `=SUM(A1:A5)`, `=AVERAGE(...)`, `=MIN(...)`, `=MAX(...)`, `=COUNT(...)`)
- Форматирование ячеек (текст, число, дата, процент) — через правый клик
- Настройка размеров таблицы (до 100×26)
- Удаление строк и колонок
- Построение линейного графика по диапазону ячеек
- Автосохранение в `localStorage`
- Полностью автономно — не требует сервера и интернета

## Запуск

Просто откройте файл `index.html` в браузере:

```bash
# Windows
start index.html

# Linux
xdg-open index.html

# Mac
open index.html
```

Или запустите через любой локальный сервер:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

## Как пользоваться

- **Ввод данных** — кликните на ячейку и начните печатать
- **Формулы** — начните ввод с `=` (например, `=A1+B2`)
- **Функции диапазона** — нажмите кнопку **fx** и выберите функцию
- **Форматирование** — правый клик по ячейке
- **График** — нажмите кнопку **График**, укажите диапазон и нажмите **Построить**
- **Удаление строки/колонки** — наведите на заголовок и нажмите **×**

## Данные

Все данные сохраняются локально в браузере через `localStorage`. При обновлении страницы таблица восстанавливается.
